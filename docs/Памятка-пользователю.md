# Памятка: консоль администрирования Яндекс 360

**Адрес:** https://y360-admin.kolmar.local

## Как войти

1. Откройте браузер (**Chrome, Edge или Яндекс.Браузер** — Internet Explorer не поддерживается, он снят с поддержки) и перейдите по адресу выше.
2. Откроется страница единого входа (ADFS). Введите **доменную** учётную запись:
   - `KOLMAR\ваш_логин` — например `KOLMAR\Kuznetsov`
   - либо `ваш_логин@kolmar.local`
   - **почта вида `ivanov@kolmar.ru` не подойдёт** — это почтовый домен, система входа его не принимает.
3. Ничего больше вводить не нужно: пароль спрашивает только ADFS, консоль его не видит и не хранит.

Доступ есть только у участников группы **`GLB-Yandex360-Admin-GRP`**. Если система ответит «Доступ запрещён: нет членства в группе» — попросите добавить вас в эту группу в Active Directory.

## Если браузер ругается на сертификат

При первом входе браузер может предупредить, что сертификат не является доверенным. Это сертификат внутреннего удостоверяющего центра (`Kolmar Root CA`).

- **Правильно:** один раз установить корневой сертификат внутреннего CA в «Доверенные корневые центры сертификации» — после этого предупреждений не будет. Сертификат можно взять у администратора или он раскатывается политикой домена.
- **Быстро и на один раз:** «Дополнительно» → «Перейти на сайт».
- ⚠️ Пока сертификат не доверенный, **вход работать не будет**: браузер на таких страницах не сохраняет куки, и вы вернётесь на страницу входа с сообщением «state не совпал».

**С домашнего компьютера** (если вы работаете по VPN) дополнительно нужно:
1. в файле `C:\Windows\System32\drivers\etc\hosts` (блокнот от администратора) добавить строку:
   ```
   10.10.0.132    y360-admin.kolmar.local
   ```
2. установить корневой сертификат внутреннего CA (см. выше).

## Что вы видите в консоли

| Страница | Что показывает |
| :-- | :-- |
| **Дашборд** | сколько всего сотрудников, сколько ожидает архивации, сколько уже в архиве, свежесть последнего снимка |
| **Синхронизация** | сравнение справочника Яндекс 360 и Active Directory: где расходятся логины, отделы, должности, СНИЛС |
| **Расхождения** | расхождения в виде списка, с возможностью посмотреть причины (в том числе «только в Яндексе» — кандидаты на увольнение) |
| **Сотрудники** | справочник сотрудников: логин, ФИО, должность, отдел, СНИЛС |
| **Архивация** | карточки архивации уволенных и их жизненный цикл: обнаружен → снимок ящика → удаление по сроку хранения |
| **Восстановление** | поиск письма в снимке и выгрузка ящика или отдельных писем |
| **Сроки хранения** | правила: какая должность сколько хранится; здесь же видно, когда какому ящику назначено удаление |
| **Журнал** | что и когда делала консоль: синхронизации, снимки, удаления, ошибки |

## Состояния ящика (жизненный цикл)

- **Обнаружен** — сотрудник пропал из Active Directory (уволился), но снимка ещё нет.
- **Снимок сделан** — архив готов, срок хранения отсчитывается от даты снимка.
- **Удаление запланировано** — снимок есть, идёт срок хранения; в карточке видна дата, когда ящик можно удалять.
- **Удалено** — ящик удалён после истечения срока.

Сроки берутся из официального перечня должностей: руководители — 3 месяца, начальники и главные специалисты — 2 месяца, остальные — 14 дней.

## Частые вопросы

**«Вход не выполнен: state не совпал»** — браузер не сохранил куку входа. Причины: не доверенный сертификат, Internet Explorer или вход по старому адресу с портом 8080. Лечится установкой сертификата и современным браузером.

**«Доступ запрещён: нет членства в группе»** — вашей учётной записи нет в `GLB-Yandex360-Admin-GRP`.

**Страница пустая или показывает старые данные** — обновите её (Ctrl+F5). Если не помогло — напишите администратору.

**Почему у всех ящиков одно состояние?** Если у всех уволенных снимки уже сделаны, все карточки находятся в состоянии «Удаление запланировано» — это нормально, а не потеря данных. Полный список людей всегда виден на странице **Архивация** во вкладке «Уволенные».

**Сколько хранятся письма?** Снимок ящика хранится всё время, пока идёт срок хранения должности; удаляется только сам почтовый ящик в Яндекс 360, архив остаётся доступным в разделе «Восстановление».

## Кому писать
